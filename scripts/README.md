Scripts for demos and benchmarks (not part of tests)

- `plot_image_contour.py`: Plot source/image contours for a chosen configuration.
  Run: `python scripts/plot_image_contour.py`

- `benchmark_mag_map.py`: Compare VBBL vs. JAX magnification map performance.
  Heavy; requires `VBBinaryLensing`. Run: `python scripts/benchmark_mag_map.py`
